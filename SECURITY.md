# Security policy

This SDK handles payment credentials and webhook signatures, so security reports are welcome.

**Do not open a public issue for a vulnerability.** Report it privately through GitHub:
Security → "Report a vulnerability" on https://github.com/damienmiheev/monobank-kotlin-sdk.
You will get an answer within 7 days. Please include the affected version and a reproduction.

Supported versions: the latest minor release of the current major version.

Vulnerabilities in monobank's own services go to monobank, not here.
